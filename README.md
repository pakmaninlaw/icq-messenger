# ICQ-мессенджер («Аська»)

Домашнее задание курса «Системный аналитик» (17.09): свой аналог легендарной ICQ на изученном сетевом стеке —
TCP/IP, WebSocket, клиент-серверная архитектура.

| Часть | Файл | Что это |
|---|---|---|
| Сервер | `server.py` | Flask + Flask-SocketIO: вход, история, рассылка сообщений, защита от подбора пароля и спама |
| Веб-клиент | открывается на `http://127.0.0.1:5055` | Окно входа, список «в сети», чат, смайлы, звук «о-оу», «печатает…» |
| Настольный клиент | `client_desktop.py` | Tkinter + python-socketio, подключается к **любому** серверу по адресу — в том числе к общему серверу группы |

## Протокол (совместим с общим сервером группы)

```
клиент -> сервер   join    {login, password}
                   message {text, time}             time в формате ЧЧ:ММ
сервер -> клиент   message {nickname, text, time}   новое сообщение
                   system  {text}                   системное уведомление
                   history [message, ...]           последние сообщения при входе
                   error   {text}                   ошибка: клиент показывает её и возвращается ко входу
расширения         users   [ник, ...], typing {nickname}
```

Защита на сервере: пароли хранятся только в виде хеша (werkzeug, PBKDF2), 5 неверных паролей подряд — временная блокировка,
не больше 5 сообщений в секунду, проверка длины и формата полей.

## Запуск (Windows)

1. Сервер: двойной щелчок по `run_server.bat` (при первом запуске поставит библиотеки) → откройте http://127.0.0.1:5055.
2. Настольный клиент: `run_client.bat`. В окне входа укажите **адрес сервера**:
   - свой сервер — `http://127.0.0.1:5055` (или IP компьютера в локальной сети);
   - общий сервер группы — адрес, логин и пароль присылает Ксения в личку. Пароль клиент не сохраняет.

Первый вход с новым ником на своём сервере — регистрация.

## Тесты

```
python tests/test_icq.py
```

Проверяются протокол, ошибки (вход без join, короткий логин, подбор пароля, спам), настоящее сетевое подключение
настольного клиента к серверу и генерация звука.
